# คู่มือติดตั้ง Secure Stack — ชุดเอกสาร

`อัปเดต 2026-10-17` · สำหรับ System Engineer (setup & deploy) · รองรับ Ubuntu 24.04 / 22.04 LTS

คู่มือติดตั้ง **Secure Stack (Ubuntu · Nginx · Tomcat 9 · MySQL)** แบบ step-by-step
ตั้งแต่เครื่องเปล่าจนระบบรันได้และปลอดภัย — ถูกแยกเป็นไฟล์ย่อยเพื่อให้เปิดอ่านและแก้ไขง่าย

## ไฟล์ในชุดนี้

| ไฟล์ | เนื้อหา |
|------|---------|
| `00-cover.md` | หน้าปก · บทนำ · ป้ายกำกับความสำคัญ (`[Critical]`/`[High]`/`[Hardening]`) · วิธีอ่าน |
| `01-สารบัญ.md` | สารบัญหัวข้อทั้งหมด |
| `หัวข้อหลัก/` | เนื้อหาหลัก หัวข้อ 1 → 10 แยกเป็นไฟล์ละหัวข้อ (`02-01-…` ถึง `02-10-…`) |
| `03-ภาคผนวก.md` | ภาคผนวก A–E (มาตรฐาน log · รายละเอียด log แต่ละตัว · ส่ง log ไป central · runbook · preventive maintenance) + สรุป "จุดที่พลาดไม่ได้" |

## วิธีใช้

1. เริ่มที่ `00-cover.md` เพื่อเข้าใจป้ายกำกับและวิธีอ่าน
2. ทำตามไฟล์ในโฟลเดอร์ `หัวข้อหลัก/` เรียงหัวข้อ **1 → 10** (ห้ามข้ามหัวข้อ 2 — การเข้ารหัสดิสก์ ทำย้อนหลังไม่ได้)
3. ใช้ `03-ภาคผนวก.md` เป็นข้อมูลอ้างอิง (มาตรฐานการเก็บ log, runbook ตอนเจอปัญหา, งานบำรุงรักษาตามรอบ)

## ข้อควรระวังก่อนเริ่ม

- 🧪 ทดสอบใน **staging** ก่อนทำกับ production เสมอ
- 🔒 ห้ามข้าม **หัวข้อ 2** (การเข้ารหัสดิสก์) — ทำย้อนหลังไม่ได้
- เปิด session SSH ค้างไว้ตอนแก้ SSH/firewall (กันล็อกตัวเอง)
